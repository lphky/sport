## 未能測試

- 真人在真鏡頭前連續做動作（尤其兩人同時）。端到端測試的影片是靜止相片切換，沒有中間動作。
- 高抬腿及平板支撐沒有找到合適的真人影片，只用相片校準；掌上壓及仰臥起坐未有雙人真人片段。
- 課室實況：多人背景、學生互相遮擋、光線不足、鏡頭太低或太近。
- 舊電腦的速度（測試機用 CPU 運算）；Safari、Firefox、真實手機。
- 測試影片數量有限（每種動作 1–3 條），不能代表所有體型、衣著及角度。

第一次在體育堂使用前，建議先用「顯示量度數值」同兩三位學生試做每種動作，如有少計或多計，按 README 的門檻調整表修改。

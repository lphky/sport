# 測試結果（2026-11-14）

環境：Debian 12、Node 22、Playwright 1.64.1 Chromium（headless）。

## 已測試並通過

- 單元測試 13 項（`node --test`）：完整深蹲 ×5 → 5；半蹲 ×3 → 0 次、嘗試 3；合格線附近抖動不重複計；站立晃動不算嘗試；離開畫面不誤計及回來要先站直；短暫失去追蹤（<0.5 秒）不中斷；極快動作（<0.5 秒）不計；難度門檻；上身前傾提示；站位檢查；多人揀最高可信度；真人實測數值合格。
- Playwright 瀏覽器測試 8 項：自由模式完整流程及紀錄保存（key 前綴 `squat-challenge:`）；目標 10 下自動結束及記錄用時、離開畫面提示；60 秒挑戰時間到自動結束；暫停（空白鍵）及 Esc 返回首頁不保存；真模型＋Chromium 模擬鏡頭由 repo 本地載入（無任何外部請求）；拒絕鏡頭權限；冇鏡頭／鏡頭被佔用；手機 390px 寬無橫向溢出。
- 真模型實測（`npm run test:real`）：三張 AI 生成的真人正面姿勢相片（站直、大腿水平深蹲、四分一蹲）砌成模擬鏡頭影片，經 PoseLandmarker（CPU）實時偵測：40 秒內數到 9 下，每次只加 1；四分一蹲不計。
- 實測發現：正面拍攝時大腿水平深蹲只量到髖降 27%、膝角 143°，原本規格建議門檻（35%／110°）永遠達不到，已改為 輕鬆 15%/155°、標準 20%/150°、深蹲 25%/145°。

## 未能驗證

- 真人用真實鏡頭連續動作的準確度（測試只用靜態相片切換，沒有中間動作、衣著及背景變化）。
- 真實 GPU 下的效能（headless 測試用 CPU，約 60ms／幀）。
- Safari、Firefox、Edge 及真實手機。
- 低光提示、多人提示只以邏輯／模擬測試，未用真鏡頭驗證。
- 音效（headless 無法聽）。

# 運動擂台 sport

用電腦鏡頭自動計數的體育堂挑戰賽。支援六種動作，可以單人挑戰，亦可以兩個人同場比賽。

- 網址：https://lphky.github.io/sport/
- 影像只在瀏覽器內處理，不上傳、不錄影。
- 純靜態網頁，不需要伺服器、帳戶或安裝。姿勢模型及程式庫都放在 repo 內，學校網絡封鎖外部網站亦可以用。

## 六種動作

| 動作 | 鏡頭角度 | 點樣先計一下（標準級） |
|---|---|---|
| 🏋️ 深蹲 | 正面或側面企立 | 膝頭屈到約 110° 或以下、髖部下降最少 19%，再完全企直。雙腳保持落地；抬腳、彎腰唔屈膝不計。 |
| 💪 掌上壓 | 側面，身體打橫 | 手踭屈到 100° 或以下、膊頭下降最少 30%，再完全撐直。塌腰、翹臀、膝頭落地不計。 |
| 🔥 仰臥起坐 | 側面，屈膝瞓低 | 上身升到離地 60° 或以上，再瞓返到 30° 或以下。只抬頭膊（捲腹）不計。 |
| ⭐ 開合跳 | 正面企立 | 手臂舉到 125° 或以上，同時兩腿打開 30° 或以上，再合埋。只舉手或只開腳不計。 |
| 🏃 高抬腿 | 正面企立 | 膝頭升到髖部高度的 70% 或以上再放低，左右腳每提一次計一下。 |
| 🧱 平板支撐 | 側面，身體打橫 | 身體直線最少 155°、上身撐離地面先計時；塌腰、翹臀、趴低即停止計時。 |

三個判定級別（輕鬆／標準／嚴格）可以在首頁揀；首頁會顯示所揀級別的實際標準。
輕鬆級的掌上壓容許跪膝，標準及嚴格級不容許。

每一下都必須「由起始姿勢出發 → 做到位 → 返回起始姿勢」先計。做一半、太快（雜訊）、離開畫面都不計。

## 玩法

- **人數**：單人挑戰，或雙人對戰（畫面中間有分界線，左、右各一位）。
- **計時賽**：30／60／90／120 秒內做得越多越好。
- **目標賽**：先做夠 10／20／30／50 下者勝（平板支撐是累積 30／60／90／120 秒）。
- **自由練習**：不限時，撳「完成」結束。平板支撐是「鬥耐力」：跌低超過 3 秒就完。
- **龍虎榜**：每個「動作＋玩法＋級別」各有一個前 10 名榜，存在這部電腦的瀏覽器內。

流程：揀好設定 → 撳「開始」→ 每位玩家做好預備姿勢並保持 1.5 秒 → 倒數 3、2、1 → 開始計數。
玩家站遠了不方便按掣，所以預備、倒數、完結都是自動的。

鍵盤：空白鍵 暫停／繼續；Enter 完成（自由練習）；R 重新預備；F 全螢幕；Esc 返回首頁。

## 擺位建議（體育堂）

- 電腦放在枱或櫃上，鏡頭大約腰至胸口高度；用投影機或大電視輸出畫面，全班都看得到。
- 企立動作（深蹲、開合跳、高抬腿）：玩家離鏡頭約 2.5–3.5 米，由頭到腳入鏡；開合跳要連舉高的手都入鏡。
- 地上動作（掌上壓、仰臥起坐、平板支撐）：身體打橫、側面對住鏡頭，離鏡頭約 3–4 米，鏡頭可以放低一些。
- 雙人：兩位分別在畫面左、右兩邊，不要越過中線。地上動作需要更闊的空間，兩人頭對頭或腳對腳排成一條橫線。
- 旁觀的同學儘量不要站在玩家身後。畫面上有顏色框的才是計數中的玩家，白色虛線框是旁觀者，不會計數。
- 光線要充足，避免背光（玩家身後有窗）。

### 追蹤與鎖定

- 單人：預備時揀最接近畫面中間的人；雙人：各自揀自己半邊最接近該半邊中間的人。
- 開始保持預備姿勢後就鎖定同一人，其他人走近都不會轉。
- 鎖定的人走開後不會自動轉人：他回到原位會自動接返；想換人，用滑鼠撳畫面上那個人。

## 在本機開啟

鏡頭只可以在 HTTPS 或 localhost 使用，不可以直接雙擊 `index.html`。

```bash
npm start          # 然後開 http://127.0.0.1:4190/
```

部署：任何 HTTPS 靜態平台都可以。GitHub Pages：Settings → Pages → 揀 main 分支根目錄。
如要嵌入其他網頁，iframe 要加 `allow="camera"`。

網址參數：`?cpu` 強制用 CPU 運算；`?sim` 測試模式（不開鏡頭，由測試程式注入關鍵點）。

## 深蹲防抬腳誤計

髖部下降改為直接對比企直時的髖部高度，避免腳踝抬高被當成蹲低。每隻腳各自記錄企直時的腳踝高度；腳踝上移超過站立腿高的 12%，連續兩個有效偵測幀確認後，取消未完成的那一下，返回企直姿勢先重新開始。畫面提示「雙腳保持落地，唔好抬腳」。單幀雜訊不直接取消，沿用原有正面 3D／側面 2D 膝角及三個難度門檻。

`THRESHOLDS.squat.maxFootLift` 控制腳踝上移容許值，`footLiftFrames` 控制確認幀數。這是鏡頭姿勢估算，不能直接量度腳掌是否接觸地面；遮擋及很小的離地動作仍有辨認限制。

## 門檻調整

所有門檻在 `js/config.mjs` 的 `THRESHOLDS`，每種動作有 easy／standard／strict 三組。

| 情況 | 調整 |
|---|---|
| 深蹲數少了 | 調高 `squat.<級別>.knee`（例如 110 → 120）及調低 `hipDrop` |
| 深蹲半蹲都計 | 調低 `knee`、調高 `hipDrop` |
| 掌上壓數少了 | 調高 `pushup.<級別>.elbow`、調低 `drop` |
| 掌上壓成日話身體唔直 | 調低 `pushup.<級別>.line` |
| 仰臥起坐數少了 | 調低 `situp.<級別>.up`；瞓低後不重新起計就調高 `down` |
| 開合跳數少了 | 調低 `jack.<級別>.arm` 或 `leg` |
| 高抬腿數少了 | 調低 `knees.<級別>.lift` |
| 平板支撐成日停 | 調低 `plank.<級別>.line` |
| 動作快時漏數 | 調低該動作的 `minRep`；或在設定改用「高速」模型提高幀數 |
| 無端端多數 | 調高 `CONFIG.startP` 或該動作的 `minRep` |

想看實際量到的數值：設定 → 開啟「顯示量度數值」。

用真人影片校準的方法：

```bash
node tools/extract.mjs 影片.webm /tmp/x.json --fps 15      # 抽出關鍵點
node tools/replay.mjs /tmp/x.json squat --trace             # 逐幀睇訊號及計數
```


## 已知限制

- 這不是醫療或專業體適能評估工具。
- 地上動作一定要側面拍攝；正面（頭向鏡頭）量度不到手踭及上身角度。
- 深蹲正面拍攝時，膝角要靠 3D 估算，準確度比側面低；要求嚴格時建議側面拍攝。
- 每幀最多偵測 3 人（單人）或 4 人（雙人）；畫面內人太多時，玩家有可能偵測不到。
- 舊電腦運算慢時，快動作（高抬腿、開合跳）可能漏數；可在設定改用「高速」模型。
